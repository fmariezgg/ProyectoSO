# Presentación del Proyecto

Este repositorio contiene la presentación del proyecto **“Desarrollo de un Prototipo de Entorno de Virtualización ‘Sandbox’ de Bajo Costo, basado en IaaS, para la estandarización de prácticas de laboratorio en Sistemas Operativos”**.  
Incluye diapositivas creadas con **Reveal.js** para exponer metodología, diseño, validación y resultados del prototipo.
